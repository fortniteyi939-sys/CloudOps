## Estado actual: Fase 1 — Setup y base del proyecto

Contiene:
- Proyecto Vite + React + TypeScript configurado
- Tailwind CSS con la paleta oficial de la práctica
- React Router con las 7 rutas del sistema
- Tipos TypeScript base (`src/types/cloud.ts`)
- Layout temporal navegable (Sidebar/Header reales llegan en la Fase 2)

## Instalación

```bash
npm install
npm run dev
```

Abre `http://localhost:5173` — deberías ver el sidebar y poder navegar entre
las 7 secciones (Dashboard, Planificación, Costos, Infraestructura, Seguridad,
Red, Servicios AWS), cada una con un placeholder por ahora.
